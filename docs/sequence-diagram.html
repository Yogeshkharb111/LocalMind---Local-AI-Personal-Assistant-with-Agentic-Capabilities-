🤖 LocalMind — Message Sequence Diagram

Low-level flow of a single Telegram message through LocalMind's LLM-first engine. Every message runs the three-stage Plan → Execute → Respond loop in engine/router.py; the model itself decides which memory, knowledge, skills, and MCP tools to use.

Actor: the person on Telegram Handler: telegram_handler/handler.py Router: engine/router.py Registry: skills/tool_registry.py LLM: local Ollama (OpenAI-compatible API) 
sequenceDiagram
    autonumber
    actor U as User (Telegram)
    participant H as TelegramHandler
    participant R as Router (Plan/Execute/Respond)
    participant M as MemoryStore
    participant TR as ToolRegistry
    participant L as LLM (Ollama)
    participant MC as MCPCoordinator
    participant RAG as RAGRetriever
    participant SK as SkillExecutor

    U->>H: send text message
    activate H
    H->>H: security gate (allowed_users whitelist)
    H->>R: process(user_id, user_name, message)
    activate R

    Note over R,M: Prepare context
    R->>M: get_soul() (persona)
    M-->>R: SOUL.md text
    R->>TR: get_all_tools()
    TR->>MC: get_tools() (dynamic MCP discovery)
    MC-->>TR: MCP tool schemas
    TR-->>R: flat tool list (memory + RAG + skills + MCP)

    rect rgba(124,156,255,0.10)
    Note over R,L: STAGE 1 — PLAN
    R->>L: chat/completions (plan prompt + tool names)
    L-->>R: step-by-step PLAN (no tools called yet)
    end

    rect rgba(124,156,255,0.16)
    Note over R,SK: STAGE 2 — EXECUTE (agentic loop, up to 15 iterations)
    loop until no more tool_calls
        R->>L: chat/completions (messages + tool schemas, tool_choice=auto)
        L-->>R: assistant message (finish_reason = tool_calls?)
        alt tool_calls requested
            R->>TR: execute(tool_name, args)
            alt memory_* tool
                TR->>M: get/save history or facts
                M-->>TR: result
            else knowledge_search
                TR->>RAG: retrieve(query)
                RAG-->>TR: top-k chunks
            else skill_
                TR->>SK: execute(skill, message)
                SK-->>TR: skill output
            else __ (MCP)
                TR->>MC: execute_tool(name, args)
                MC-->>TR: JSON-RPC result
            end
            TR-->>R: tool result (string)
            R->>R: append tool result to messages
        else no tool calls
            R->>R: exit loop
        end
    end
    end

    rect rgba(124,156,255,0.10)
    Note over R,L: STAGE 3 — RESPOND
    R->>L: chat/completions (plan + collected results)
    L-->>R: final natural-language reply
    end

    Note over R,M: Persist the turn
    R->>M: add_turn(user_id, message, reply)
    R->>M: append daily log (data/daily_logs/YYYY-MM-DD.md)
    R-->>H: final reply text
    deactivate R

    H->>U: reply (auto-split if > 4000 chars)
    deactivate H
